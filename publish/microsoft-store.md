Render Markdown — Mermaid, math, code — in the File Explorer preview pane. Offline, no admin.

**Description:**
MdPreview shows your Markdown files rendered right in the Windows File Explorer preview pane (press Alt+P),
so you can read `.md` without opening an editor.

What it renders that the basic previewers don't:
• Mermaid diagrams (flowcharts, sequence, class, state, and more)
• Math (KaTeX, inline and block)
• Syntax‑highlighted code, with language auto‑detection and a copy button
• GitHub alerts (NOTE/TIP/WARNING), tables, task lists, footnotes, emoji shortcodes
• A floating outline of the headings, and find‑in‑page (Ctrl+F)
• Light and dark themes that follow Windows

Private and offline by design: the preview never connects to the internet, scripts inside a Markdown file
never run, and remote images are blocked by default (you can turn them on). It also appears in classic
Outlook's attachment preview.

Fast: a one‑time cache warm‑up means diagrams render quickly and stay quick.
